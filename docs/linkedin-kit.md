## Tagline principal

Scaffold CLI para iniciar projetos full stack com Express, Nest ou FastAPI já com validação, DI, JWT e PostgreSQL opcional.

## Outras opções de tagline

- Comece projetos full stack mais rápido, sem começar do zero.
- Uma CLI para gerar bases backend e frontend mais próximas de produção.
- Menos tempo em setup, mais tempo construindo produto.

## Post para LinkedIn

Criei uma CLI chamada `create-stack-cli` para acelerar o início de projetos full stack.

A ideia nasceu de um problema muito simples: boa parte do tempo no começo de um projeto vai embora com setup repetitivo.

Em vez de começar toda vez do zero, a CLI gera uma base com:

- Express, Nest ou FastAPI
- Next.js ou Vite + React
- validação pronta
- DI
- JWT
- PostgreSQL opcional
- estrutura inicial de backend organizada em camadas
- Docker Compose para infra local

O ponto mais importante para mim foi manter o projeto genérico.

Eu removi tudo que deixava o scaffold preso a um contexto específico de empresa ou arquitetura interna e deixei a ferramenta mais reutilizável para qualquer pessoa que queira começar um projeto com mais velocidade e uma base mais sólida.

Se a proposta fizer sentido para você, posso compartilhar o repositório e seguir evoluindo com novos templates.
